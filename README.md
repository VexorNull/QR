## 🚀 Overview

1. **VexorNull Enterprise Credential Studio** is an advanced web-based platform designed for organizations, institutions, and secure enterprises to instantly generate digital passes, employee badges, and verified identification credentials. 
2. Built entirely on client-side rendering, ensuring zero server data storage and maximum privacy and security.

---

## ✨ Core Features (PRO v18.0)

1. **Cryptographic QR Code & Barcode Integration:** Real-time data encryption generating secure QR and linear barcodes.
2. **Dynamic Avatar Synchronization:** ID card profile pictures automatically link dynamically with the verification popup modal.
3. **Holographic Security Stamp:** Professional enterprise aesthetics featuring official verification seals and watermark ribbons.
4. **Custom Theme Engine:** Multiple accent color modes (Blue, Emerald, Purple, Amber) and Dark/Light corporate card switching.
5. **Auto-Save & LocalStorage:** Browser-based data caching to prevent data loss on refresh.
6. **Clean Image Export:** Seamless html2canvas integration to download high-resolution PNG ID cards.
7. **Fully Responsive Layout:** Optimized user interface across mobile, tablet, and desktop screens.

---

## 🛠️ Tech Stack

Built using modern web technologies and lightweight libraries:
1. **HTML5 & CSS3** (Semantic markup & Custom styles)
2. **Tailwind CSS** (Utility-first styling & Dark mode)
3. **QRCodeJS** (Client-side cryptographic QR rendering)
4. **Html2Canvas** (DOM-to-image conversion for card downloading)
5. **FontAwesome 6** (Modern UI iconography)
6. **Google Fonts** (Plus Jakarta Sans typography)

## 🚀 Getting Started & Local Setup

No complex backend setup is required since this project is purely frontend-based.

1. **Clone the repository:**
```text
git clone https://github.com/vexornull/QR.git
```
2. **Navigate to project directory:**
   ```text
   cd QR
   ```
4. **Run the application:**
   - Open index.html directly in any preferred web browser.
   - Alternatively, use the Live Server extension in VS Code.
